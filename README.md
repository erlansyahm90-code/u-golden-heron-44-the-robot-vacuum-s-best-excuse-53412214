## What it does

`main.py` writes the robot vacuum's one-line excuse for missing a spot to `/output/entry.txt` — 126 characters, well within the 140-character gate.

The excuse is rooted in the vacuum's own world: its map insists the spot is a lake now, and the vacuum does not argue with the map — because the map has never once apologized to it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
